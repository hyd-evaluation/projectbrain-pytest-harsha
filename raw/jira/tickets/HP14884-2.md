# HP14884-2 — Define black-box verification for cache boundary behavior

**Type:** Task · **Status:** To Do · **Priority:** Medium

## Description

Prepare a black-box verification plan for the reported cache-boundary problem.

Cover these observable outcomes without prescribing an implementation:

- cache reads do not retrieve data from outside the configured cache area;
- cache writes do not create files or parent directories outside that area;
- cache directory creation remains inside that area;
- cache inspection does not display contents of an outside file;
- ordinary namespaced plugin cache keys continue to work;
- behavior is checked on supported path semantics, including Windows-relevant absolute/rooted forms.

Use isolated temporary directories and sentinel files. Record commands, observed paths, process results, and output. Do not include proposed code changes or details of any later implementation.
